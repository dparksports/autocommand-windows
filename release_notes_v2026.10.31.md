# AutoCommand v2026.10.31

Self-contained Windows build — **no .NET installation required**. Unzip and run `AutoCommand.exe` as Administrator.

## Highlights

- **New tab: Data & Privacy.** The Windows Defender tab shows what Defender *does*; this one answers what it *shares*, with whom, and what you can do about it — read live from your machine, never hardcoded.
- **Your data-sharing settings, in plain English.** Cloud-delivered protection (MAPS), automatic sample submission (with Group Policy overrides surfaced as "policy N"), cloud block level, Windows diagnostic data level, SmartScreen, and Smart App Control — each card shows the current value, one sentence on what it actually sends (file hashes and certificates ≠ file copies), and a button deep-linking into Windows Security / Settings, the supported place to change them. The tab is deliberately read-only: several of these values are tamper- or policy-protected, and Windows Security collects the confirmation itself.
- **"Managed by an organization" banner.** Domain join, MDM enrollment, or Defender policy keys flip an honest warning: your administrator may own these settings and local changes can revert on policy sync — the same keys our own hardening presets write, so power users see exactly when they're in policy territory.
- **Who can receive this data — curated, with sources.** Five categories (Microsoft first party; contracted processors; security-intelligence sharing via the Virus Information Alliance; legal/government recipients with aggregate-only reporting; and where you can see what's held — the Microsoft privacy dashboard and Diagnostic Data Viewer). Every entry links its primary source with a verified date. Where Microsoft doesn't publish names for consumer Windows, the list says exactly that instead of inventing vendors.
- **Exercise your rights (US) — draft-letter builder.** Two legally distinct flows, kept separate: **corporate privacy requests** (CCPA/CPRA and the VA/CO/CT/UT/TX/OR/MT statutes — routed through Microsoft as the business, covering file samples, cloud-lookup metadata, detection reports and related telemetry, with per-state citations and response deadlines) and **FOIA + Privacy Act requests to federal agencies** (agency picker with portal links, fee-waiver and expedited-processing options) — because FOIA applies to agencies only, never to companies. Generated letters open in an editable box; copy or save as .txt. **AutoCommand never sends anything, and this is not legal advice.**
- **Request tracker + evidence export.** A local-only log (no cloud, nothing synced) records each request and computes the statutory due date when you mark it sent. One click exports this machine's full settings snapshot as timestamped JSON — attach it to a letter or keep it to detect drift.

> **Note:** run elevated as usual. The settings read uses the same PowerShell surface as the Defender tab; nothing on this tab changes system state, and the request tracker lives in `%LOCALAPPDATA%\AutoCommand\privacy-requests.json`.
